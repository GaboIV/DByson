# Registros de decisiones de arquitectura (ADR)

Cada ADR explica una decisión que no es obvia leyendo el código: el contexto, lo que se eligió y lo que se sacrificó.
Un ADR aceptado no se edita; si la decisión cambia, se escribe uno nuevo que lo reemplaza.
